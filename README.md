# Ecommerce KPI Analysis

Data Analytics project focused on analyzing eCommerce performance through sales data, customer behavior and business KPIs.

## Objectives

- Analyze sales performance
- Identify key business metrics
- Build dashboards for decision-making
- Generate actionable insights

## Tools

- Python (Pandas, NumPy)
- SQL
- Power BI
- Jupyter Notebook
- Excel

## Project Structure
data/ Raw and processed datasets
notebooks/ Exploratory analysis notebooks
sql/ SQL queries
src/ Python scripts
dashboards/ BI dashboards
docs/ Documentation
